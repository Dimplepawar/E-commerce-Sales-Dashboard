# E-commerce-Sales-Dashboard
🚀 Excited to Share My E-commerce Sales Dashboard Project in Power BI 📊🛒

I recently completed an end-to-end Data Analytics project where I built an interactive E-commerce Sales Dashboard using Power BI to transform raw sales data into actionable business insights.

🎯 Project Goal
The objective of this project was to analyze e-commerce sales performance and create a dashboard that helps businesses quickly understand:
• Overall sales & profit performance
• Regional sales trends
• Product category performance
• Shipping analysis
• Monthly sales growth patterns

📌 Key Insights from the Dashboard
• Generated over 5M in total sales
• Analyzed 25K+ order quantities
• Tracked 2M overall profit
• Monitored shipping costs and category-wise performance
• Identified top-performing states and product categories

📖 Dashboard Highlights
• KPI cards for quick business overview
• Monthly sales trend analysis
• State-wise sales comparison
• Category and segment analysis
• Interactive filters for dynamic reporting

🛠️ Tools & Skills Used
• Power BI (Dashboard creation & visualization)
• Excel (Data cleaning & preprocessing)
• Power Query (Data transformation)
• DAX (Measures & KPIs)
• Data Visualization & Business Analysis

This project helped me improve my skills in data cleaning, dashboard designing, and deriving business insights from data.
